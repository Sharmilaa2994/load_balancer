# AI-Based Server Load Balancing Simulator

## Overview

AI-Based Server Load Balancing Simulator is an intelligent web-based application developed to simulate and visualize server load distribution using Artificial Intelligence concepts. The project demonstrates how incoming network requests can be distributed efficiently across multiple servers using both traditional and AI-driven load balancing techniques.

The application provides real-time monitoring of server loads, request allocation, traffic handling, performance comparison, and interactive visualization dashboards. It is designed as an educational and demonstration project for understanding server management, distributed systems, AI-based optimization, and network traffic balancing.

The system is developed using Flask for backend operations along with modern frontend technologies for an interactive and responsive user experience.

# Working Principle

## Step 1: Request Generation

The simulator generates incoming client requests to mimic real-world network traffic.

## Step 2: Server Monitoring

The system continuously monitors the load and status of available servers.

## Step 3: AI-Based Decision Making

The AI logic analyzes server performance, current load, and traffic conditions to determine the best server for request allocation.

## Step 4: Request Allocation

Incoming requests are distributed dynamically among servers based on balancing algorithms.

## Step 5: Performance Visualization

The dashboard displays server utilization, traffic flow, and load balancing performance in real time.

---

# Modules Description

## 1. Dashboard Module

The dashboard acts as the main interface of the application, displaying server activity, request traffic, and performance insights.

## 2. Load Balancing Module

This module contains the logic for distributing incoming requests among multiple servers.

## 3. AI Decision Module

The AI engine evaluates server loads and intelligently selects the most suitable server.

## 4. Monitoring Module

This section continuously tracks server activity, response behavior, and workload distribution.

## 5. Simulation Module

The simulator generates virtual traffic to test balancing efficiency under different conditions.
